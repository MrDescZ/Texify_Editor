# Textify Editor

**Textify Editor** is a lightweight, open-source code editor for Windows.

It started as a personal project and has gradually grown into a full editor with a modern dark interface, developer-focused tools, and a few visual touches to make the experience feel smoother and more enjoyable.

> ⚠️ **Textify Editor is still actively developed.** Some features may change, improve, or be replaced over time.

---

## Features

### Editor

* Syntax highlighting
* Line numbers
* Multiple file support
* Search & replace
* File opening and saving
* Recent files
* Support for multiple programming languages
* Customizable editor experience

### UI & Visual Effects

* Modern dark-themed interface
* Smooth UI animations
* Animated transitions
* Visual feedback for buttons and controls
* Custom borders and UI styling
* Clean and responsive layout

### Performance

* Lightweight
* Fast startup
* Designed to work well on everyday Windows PCs
* No unnecessary background services

## Getting Started

### Requirements

To build Textify Editor from source, you'll need:

* Windows
* Visual Studio 2022 or newer
* .NET Framework 4.8 Developer Pack
* Git
* Required NuGet packages

### Build

1. Open the `.sln` file in Visual Studio.
2. Restore the required NuGet packages.
3. Select the desired build configuration.
4. Build the solution.
5. Run the application.
